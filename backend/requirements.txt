# Two things depend on this, and they are not equally optional:
#
#   1. Cross-encoder reranking in rag.rerank_chunks — genuinely optional,
#      falls back to embedding-similarity order when absent.
#   2. Local embeddings in embeddings.py — NOT optional. This is the
#      default provider whenever OPENAI_API_KEY is unset, and without it
#      a keyless deployment has no way to embed anything, which puts back
#      the exact cliff this app is built to avoid: no key, no vectors, no
#      chunks, no chat.
#
# It was previously commented out because torch is enormous. The size
# objection was real but the fix is the CPU wheel, not omission — the
# backend never touches a GPU, and backend/Dockerfile installs from
# PyTorch's CPU index, which is a few hundred MB rather than ~800MB of
# bundled CUDA libraries. Installing this file WITHOUT that extra index
# still works; it just produces a much larger environment.
